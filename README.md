# GoCepat

Ujian take-home Data Structures and Algorithms (studi kasus aplikasi transportasi online GoCepat).

| Soal | File | Cara menjalankan |
|---|---|---|
| Soal 1 (polymorphism, aggregation, abstraksi) | `Main.java` | `javac Main.java && java Main` |
| Soal 3 (BFS driver terdekat, array buatan sendiri) | `GoCepat.java` | `javac GoCepat.java && java GoCepat` |

Persyaratan: JDK 11 atau lebih baru.
Struktur data pada Soal 3 dibuat sendiri dengan array (tanpa Collections Framework).
